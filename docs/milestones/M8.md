# M8 report — Mission Intent schema and deterministic compiler

Date: 2026-09-11 · Plan ACs: AC-23, AC-24, AC-25, AC-26 · Grounding: ADR 0010 rule 6, ADR 0013, `docs/research/LLM-EMBODIMENT.md` §5.2–§5.3

## Plan (as executed)

1. Closed-vocabulary JSON Schema `mission/schema/mission_intent.schema.json`. Geographic
   literals and actuator vocabulary are rejected (`additionalProperties: false`).
2. Site model `mission/site/demo_farm.yaml` (hashed into every plan). The keep-in fence is
   the polygon a SITL run also loads into the arbiter (ADR 0004).
3. Deterministic compiler `mission/compiler/` with one named check per constraint in
   `LLM-EMBODIMENT.md` §5.3. Independent verifier `mission/compiler/verify.py` re-derives
   containment from serialised waypoints so AC-28 is not a tautology.
4. Stop grammar `mission/compiler/stop_grammar.py` matches `abort` / `land_now` /
   `return_home` before any model exists.
