## Defect found and fixed

- Ogma binary in the FM image was installed with `install` of the executable only, so
  `Paths_ogma_core` still expected `/root/.cabal/share/.../ogma-core-1.15.0/data/variable-db.json`.
  Generation stages those data-files before calling `ogma` (`scripts/generate.sh`); `Dockerfile.fm`
  copies them at image build time for the next rebuild.
- Copilot rejected `input_signal > -1.5` (mix of infix `>` and prefix `-`) and
  `input_signal + 1.5 > 0` (`(+)` not the Float stream operator in this spec's imports).
  REQ-ALT-01 uses `input_signal >= 0` (no climb). A numeric ceiling in metres is [PARAMETER TBD].
