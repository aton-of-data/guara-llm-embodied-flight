# Project Guará — agent memory

## Language
- All output in English: chat replies, docs, code, comments, commit messages, reports.
- Keep replies terse: no restating the request, no preamble, no closing summaries of unchanged context.
- Regulatory source excerpts may stay in their original language when quoted; paraphrase in English.

## Mission
One RTA architecture (ASTM F3269 roles), two domains. Scope map: `docs/operations/README.md`
— one document per flight operation, air and space. A new operation gets its document before
it gets code.

### Air (implemented and measured) — PX4 via ROS 2
- Copilot monitors generated by Ogma from FRETish requirements
- DAA with DAIDALUS v2 (separate package, NOSA license)
- geofence violation prediction
- RTA arbiter implemented as ModeExecutor (px4-ros2-interface-lib)
- recovery function = PX4 internal modes (Hold / RTL / Land)

### Space (specified) — F´ v4.3.0
- same DecisionCore, arbiter as an FPP component on a rate group (ADR 0011)
- channels replace, not extend, the air set: attitude_keepout, power_margin, momentum,
  inputs_valid, requirements. No DAA channel, ever (ADR 0012).
- recovery function = a safe mode that does not exist in F´ and must be written (risk RS-1),
  latched: released only by ground command
- Rule O: space/F´ work never precedes the PX4 latency and batch results

Long-term goal (docs/research/LLM-EMBODIMENT.md): open-source, voice-driven LLM
operation of civil drones (e.g. agriculture), with the LLM as the untrusted
Complex Function bounded by the Guará RTA.

## Fixed truths
- API source: only code cloned in third_party/ with commit pinned
  in third_party/VERSIONS.md. Never infer API from memory.
- PX4, px4_msgs and px4-ros2-interface-lib at mutually compatible commits.
- ROS 2 distro: Humble. PX4 version: v1.17.0. Ogma: v1.15.0.

## Engineering
- C++17, colcon/ament, gtest + launch_testing.
- Every safety function has a test that fails before the implementation.
- Arbiter decision path without dynamic allocation and with bounded time.
- SITL always headless and reproducible (seed + commit recorded).
