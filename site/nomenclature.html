1 · Symbols

Parameters are configuration values. Signals are evaluated once per decision tick. Measurements are quantities obtained from a recorded run and are not configurable.

Symbols used in the switching rule and the latency budget.

SymbolUnitKindDefinition
δ_latsmeasurement End-to-end switch latency: from the input sample that makes U(k) true to the recovery mode being effective. Reported as a p99 over a batch.
τ_gfsparameter Geofence trigger threshold. The switch is commanded when the predicted time to keep-in violation falls to this value.
τ_daasparameter Detect-and-avoid trigger threshold, against the time to the corrective well-clear volume.
τ_recsmeasurement Recovery settling time: from entry into the recovery mode until the vehicle reaches the recovered condition. For Hold, until horizontal speed falls below 0.5 m/s.
τ_rec,daasmeasurement The value of τ_rec applicable to the recovery selected for a detect-and-avoid trigger.
T_gfssignal Predicted time to keep-in geofence violation, including the braking model and position uncertainty. Positive infinity when no violation is predicted.
T_daassignal Minimum over intruders of the time until the ownship enters the corrective-level well-clear volume. Positive infinity when no intruder is predicted to enter it within the lookahead time.
h_gf, h_daasparameter Additive hysteresis applied to the corresponding threshold on the return path only. They never delay the switch away from the complex function.
T_dsparameter Dwell time. Both the minimum time spent in a recovery function and the minimum continuous duration for which C(k) must hold before a return is permitted.
T_ssparameter Decision period. The switching logic is evaluated once per tick of this period.
T_escsparameter Persistence escalation time. Disabled by default.
N_max—parameter Switch budget. After this many complex-function-to-recovery switches within the window W, the recovery latches.
Wsparameter The sliding window over which the switch budget is counted.
S(k)—signal Number of switches recorded within the window W at tick k.
Cdur(k)ssignal Duration for which the clear condition C has held continuously up to tick k.
Design obligation O-1

The switching rule is meaningful only where τ_gf ≥ δ_lat and τ_daa ≥ τ_rec,daa + δ_lat. A trigger threshold shorter than the measured time to act is a threshold that does not act in time. Evaluated against the published batch in Evidence §1.

2 · States and signals

States of the switching logic.

StateMeaning
INACTIVEGuará holds no authority. Entered on any remote-pilot or ground-station mode change and on any platform failsafe.
CFThe complex function has the vehicle, through the gateway, subject to the envelope clamp.
RF(r)A recovery function is active, where r is one of HOLD, RTL or LAND.
LATCHED(r)The recovery is held and no return is permitted. Entered on exhaustion of the switch budget or on actuation failure.

Boolean signals evaluated at each decision tick.

SignalSourceDefinition
U(k)derivedUnsafe predicate. Commands a switch to the recovery function within the same tick.
C(k)derivedClear predicate. A necessary but not sufficient condition for return; see T_d.
M(k)monitorsTrue when any switch-class runtime monitor reports its property violated.
V(k)input managerInput-invalid flag. True when any enabled channel is stale, absent or malformed. Enabled channels fail closed.
IC(k)platformIn-charge flag. True when Guará holds the authority it believes it holds.
cf_intent_unsafegatewayShadow check: true when the setpoint the complex function is currently proposing would itself violate the fence. Withholds return; never by itself a reason to leave CF.

3 · Latency stages

δ_lat is reported as a sum of named stages, each measured on a clock validated for that stage. Stating the decomposition is what makes it possible to say which stage is excluded, and why.

Stages of the end-to-end latency budget.

StageClockInterval
L0platformSensor sample to platform publication.
L1mixedPlatform to ROS 2 transport. Excluded from δ_lat while clock alignment exceeds its limit.
L2monitorMonitor input reception to verdict publication.
L3ROSVerdict timestamp to arbiter reception.
L4steadyArbiter reception to the decision tick that sets U(k).
L5steadyDecision to command publication.
L6steadyCommand to recovery mode effective.

6 · References

External works cited on this site. Upstream software is cited at the commit pinned in third_party/VERSIONS.md; the repository re-derives every API fact from that pinned source rather than from documentation.

Standards and regulation

  1. ASTM F3269, Standard Practice for Methods to Safely Bound Flight Behavior of Unmanned Aircraft Systems Containing Complex Functions. ASTM International. Not held by this project; the role mapping is marked [REVIEW] and is an open ask (R-8).
  2. RTCA DO-365 and DO-365B, Minimum Operational Performance Standards for Detect and Avoid Systems. RTCA. Source of the well-clear definitions; thresholds are written for larger aircraft than the reference airframe (R-5).
  3. ANAC RBAC 100, Brazilian civil regulation for unmanned aircraft, in force from 2026-06-16. Marked [REVIEW] throughout the repository.

Upstream software

  1. PX4 Autopilot v1.17.0, and the Auterion px4-ros2-interface-lib, release/1.17. The arbiter is realised as a mode executor against this interface.
  2. ROS 2 Humble Hawksbill. Companion-side runtime for every node outside the autopilot.
  3. NASA FRET v3.1.0, formal requirements elicitation tool. NOSA-licensed; used for generation only.
  4. NASA Ogma v1.15.0, monitor generation. Targets cFS, ROS 2, F´ and standalone; no PX4 target, which is gap G2.
  5. Copilot v4.8.1, stream-based runtime verification producing verified C99.
  6. NASA DAIDALUS v2.0.3a, detect-and-avoid reference implementation. NOSA-licensed and isolated to nosa/.
  7. NASA F´ v4.3.0, flight software framework. Second host for the switching core; provides no safe mode, which is risk RS-1.
  8. NASA ICAROUS, integrated safe-drone stack, final release V-2.2.6, January 2022. Gap G1.

Literature

  1. A. Robey et al., Jailbreaking LLM-Controlled Robots (RoboPAIR), 2024. Reports a 100% jailbreak rate against three LLM-controlled robots. arXiv:2410.13691. Motivates a boundary independent of the model.
  2. Runtime monitoring work reported at CAV 2024 (Volocopter/DLR) and Platum at NFM 2026, both of which leave automatic contingency triggering as future work. Gap G4.
  3. Natural-language drone control prior art surveyed in docs/RELATED-WORK.md: ChatGPT for Robotics, TypeFly, EchoPilot, MAVLinkMCP, AerialClaw. The shared safety pattern is prompt engineering, tool restriction and human override.
Citation practice

No preprint exists. Cite the repository and the commit, via CITATION.cff. A quantitative claim should cite the run directory under docs/evidence/ that produced it, not this site.
